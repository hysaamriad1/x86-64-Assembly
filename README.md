# x86-64 Assembly

This repository is a collection of small x86-64 assembly examples for beginners. I’m sharing the samples I work through as I learn, including the ideas and techniques that helped me get started.

## What you’ll find here

- Small, focused examples that introduce assembly concepts step by step
- Source code with explanations where they’re useful
- Notes about building or running an example when it needs specific tools or setup

The repository will grow as I learn. Examples may assume a particular assembler or operating system, so check the notes in each sample before building or running it.

## Getting started

Browse the examples and try them in order. If you’re new to assembly, take your time reading the code and experimenting with small changes. The instructions and requirements for each example will be included alongside it.

## About

These are learning samples, not a complete guide or a polished reference. I hope they make learning x86-64 assembly a little more approachable for other beginners.
